# Tonypony's Company Demo Site

Static demo website for a fictional design, architecture, and building company.

## GitHub Pages

This project has no build step. Publish the repository with GitHub Pages using:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

The site uses relative paths, so it works from a repository path such as `https://yourname.github.io/demo-company-page/`.

## Files

- `index.html` - page content and structure
- `styles.css` - responsive visual design
- `script.js` - mobile nav and project filters
- `assets/images/` - generated local demo imagery
